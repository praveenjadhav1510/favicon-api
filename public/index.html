Why this API

Built to never fail

Most favicon APIs break on subdomains or private routes. This one doesn't.

Deep HTML Extraction

Parses the actual HTML of your target URL to find icon and Apple Touch Icon link tags.

Smart Domain Fallback

If a subdomain is private or fails, retries the root domain automatically to find site branding.

Quality Scoring

Ranks candidates by resolution and type — SVG and high-res PNGs are always preferred.

Icon Validation

Every candidate is verified with a HEAD request to confirm it's a real image before responding.

LRU Cache

Repeat requests return instantly from a 500-entry, 24-hour cache — zero redundant network calls.

Secured with API Keys

All routes are protected. Pass your key via header or query param — flexible and secure.

Postman & Code Snippets

Test in seconds

Pick a language and copy the snippet directly into your project.

cURL 
# Step 1 — Set method to POST in Postman
# Step 2 — Enter URL:
POST https://your-domain.vercel.app/api/favicon

# Step 3 — Headers tab, add:
x-api-key: your_api_key_here

# Step 4 — Body → raw → JSON:
{ "url": "https://github.com" }

# Or run directly in terminal:
curl -X POST https://your-domain.vercel.app/api/favicon \
     -H "Content-Type: application/json" \
     -H "x-api-key: your_api_key_here" \
     -d '{"url": "https://github.com"}'
const res = await fetch("https://your-domain.vercel.app/api/favicon", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-api-key": "your_api_key_here",
  },
  body: JSON.stringify({ url: "https://github.com" }),
});

const { favicon } = await res.json();
console.log(favicon.href); // → favicon image URL
import axios from "axios";

const { data } = await axios.post(
  "https://your-domain.vercel.app/api/favicon",
  { url: "https://github.com" },
  { headers: { "x-api-key": "your_api_key_here" } }
);

console.log(data.favicon.href); // → favicon image URL
import requests

res = requests.post(
    "https://your-domain.vercel.app/api/favicon",
    headers={
        "x-api-key": "your_api_key_here",
        "Content-Type": "application/json",
    },
    json={ "url": "https://github.com" },
)
print(res.json()["favicon"]["href"]) # → favicon image URL
1

Set Method & URL

Set method to POST and enter your API URL ending with /api/favicon.

2

Add API Key

Go to Headers, add key x-api-key with your secret as the value.

3

Set JSON Body

Go to Body → raw → JSON and enter {"url":"https://github.com"}.

4

Read the Response

Check favicon.href in the JSON — that's your icon URL, ready to use.
